## Sobre mim

Sou desenvolvedor com foco em backend, automação e práticas DevSecOps. Tenho
interesse em construir APIs, integrar serviços e trabalhar com bancos de dados,
mensageria, containers e observabilidade.

Atualmente, estou aprofundando meus conhecimentos em Java com Quarkus, SRE,
observabilidade, Kubernetes, ambientes cloud native e segurança aplicada ao
desenvolvimento.

## Desenvolvimento com IA

Estou no início dos estudos em desenvolvimento de software apoiado por IA,
com interesse em criar agentes personalizados e automatizar fluxos de
desenvolvimento. Ainda não tenho uma implementação de agente em produção; neste
momento, estou construindo a base conceitual e técnica para evoluir nessa área.

Meus estudos estão concentrados em:

- Agentes personalizados para desenvolvimento;
- Prompts, skills e instruções reutilizáveis;
- MCP e integração entre ferramentas;
- Governança, testes e qualidade em fluxos de IA;
- Desenvolvimento orientado por especificações.

O [DARP CLI](https://github.com/darpbr/darp-cli) é meu projeto autoral nessa
frente, atualmente em desenvolvimento inicial. A proposta é criar uma CLI para
descobrir, instalar, versionar e gerenciar ativos reutilizáveis de IA, como
prompts, instruções, skills, personas, servidores MCP e workflows.
